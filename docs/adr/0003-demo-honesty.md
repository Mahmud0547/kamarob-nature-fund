# 3. The demo is labelled as a demo

Date: 2026-10-02 · Status: accepted

## Context
The first version presented an organisation and figures (trees planted, villages, volunteers) that do not exist.
The site is shown to real organisations, which may check.

## Decision
Every page says it is a demo platform; sample content is labelled; only the photos, videos and the author's own trip
are presented as real. A unit test fails if the old invented figures return.

## Consequences
Clients see exactly what was built and nothing that could later damage trust.
